# Alop for Mac

**Music belongs on your desktop.** Alop is a free native macOS companion that brings Spotify album artwork to your desktop, extends its colors into an immersive backdrop, and adds a small glass playback controller beneath the cover.

> **Version 1.0.0 · macOS 14 Sonoma or later · Spotify for Mac**

## Download

Download the latest installer from [Releases](https://github.com/nitheesharrrr/alop-mac-download/releases/latest):

**Alop-macOS-unsigned.dmg**

The download is a drag-to-install disk image. Open the DMG and drag **Alop** into **Applications**.

### First launch notice

This release is **not Developer ID signed or notarized**. macOS may show a warning that it cannot verify the developer. Only run software you trust. If you decide to open Alop, control-click it in Applications, choose **Open**, and review macOS’s prompt.

## What’s included

- Follow Spotify’s current track and display the original album artwork on selected Mac displays.
- Extend a softened version of the cover into a full-screen desktop backdrop.
- Adjust artwork size, backdrop strength, color palette, brightness, framing, and transitions.
- Use a compact glass controller for previous, play/pause, and next; optionally hide it or toggle it from the artwork.
- Show configurable intermission scenes when Spotify reports an ad break, including Color Drip, Color Wipe, Loading Ring, Rising Bars, Aurora Flow, Slow Bloom, and Shuffle.
- Set intermission background and accent colors.
- Choose which connected displays show artwork.
- Keep the Mac awake for a timed listening session, with optional Dock and menu-bar hiding.
- Open controls and settings from the menu bar, with a first-launch Spotify setup guide.

Spotify is the supported playback source in this release. Alop reads the current Spotify playback locally through macOS Automation. It does not select tracks or change playlists; playback commands are sent only when you press a control.

## System requirements

- macOS 14 Sonoma or later.
- Spotify for Mac installed and open.
- Internet access to load album artwork from Spotify’s image service.
- macOS Automation permission for Alop to read Spotify playback.
- A built-in or connected display.
